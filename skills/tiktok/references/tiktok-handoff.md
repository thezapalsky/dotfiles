# Captions and TikTok Studio handoff

Read when asked to draft captions, choose covers/music, upload, save a draft or schedule a post. Editing alone does not authorize account changes. Use the publishing action explicitly requested in the current task.

## Caption format

For the established chase series, continue the approved title and public episode number. Keep captions spoiler-free: no pull names, total values, best-card names or outcome commentary. Use the title, a blank line, a short booster-count line, another blank line, then the relevant hashtags. Example:

```text
open some boosters with me! (pt.N)

three booster packs

#MTG #MagicTheGathering #PackOpening
```

For consecutive three-pack episodes, approved wording can be `three booster packs`, `three more booster packs`, then `the last three booster packs`. Use `three`, not a misheard `free`. These phrases describe this batch, not the end of the overall chase. Confirm pack counts and episode numbers from project/publishing records; do not restart the series for a new purchase. Adapt captions for other sets or bulk purchases instead of copying unrelated hashtags.

## Drafts and scheduling

1. Confirm the exact final video version and intended account from visible UI or connected tools. When Chrome is requested or already contains the TikTok login, open TikTok Studio in that existing Chrome session using available browser-automation or computer-use tools. Prefer browser controls for reliable background-tab operation; use visual computer control when the interface requires it. Inspect the actual page state before acting. Do not start a separate signed-out profile or copy session credentials. If asked to avoid interrupting media, use background-tab control when supported; do not switch focus, pause their playback or start an audible preview while their media plays. Report any required step that cannot be done without interruption.
2. Upload only the requested clip, add the approved or requested draft caption and relevant hashtags, and select a representative cover. Prefer a readable booster/product or card frame, an uncluttered crop and a modest zoom if the UI supports it. Avoid revealing the best pull through the cover when preserving suspense. Do not change the underlying card artwork.
3. Add background music in TikTok Studio when requested and available in that interface/account. When requested, choose a different fitting track per episode and start with default in-app volume; do not silently apply an unrelated preset gain. Audition the mix with the original sound and effects. Do not promise a particular sound is popular or available without checking. If the web UI lacks the required music feature, report it instead of claiming music was added or silently baking it into the local file.
4. For **draft only**, save and verify the persisted draft in the draft list, including the correct clip/caption and any available cover/music confirmation. Do not click Publish or Schedule. An upload finishing, enabled button or unsaved editor view is not proof of a saved draft. Stop once the requested draft is verified.
5. For **explicitly authorized scheduling**, resolve relative dates to actual dates in the user's timezone. Store episode-to-file, date, local time and timezone in a publishing manifest. Verify each persisted scheduled entry after saving, including the episode, date/time and caption. Use explicit dates in the manifest rather than reusing an old project schedule.

Check current official TikTok documentation and the actual account/UI before choosing an API or browser scheduling workflow. Do not assume OAuth scopes, app audit approval, public posting access or a native scheduling field. User authorization and capability are separate checks. Avoid duplicate drafts/posts when retrying: inspect current state before re-uploading.

Save the final caption text, cover timestamp/crop, selected music title/artist when available, actual music settings, action/status, and verification evidence alongside the final artifact. Report partial completion precisely if a step is unavailable.
